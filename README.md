# Stevebot

Headless-бот для Minecraft Java Edition на Node.js + Mineflayer: чат-команды, локальный CLI и русифицированный Web GUI.

## Возможности

- Авто-атака враждебных мобов в радиусе 24 блока (включая фантомов)
- Ближний бой: меч → топор → рука
- Авто-экипировка брони, щита и лучшего оружия из инвентаря
- Авто-еда при голоде < 14, зелья при HP < 10, золотые яблоки при HP < 6
- Выживание: гребёт в воде, выпрыгивает из лавы, фиксирует падения
- Добыча с подходящим инструментом, защита кровати от разрушения
- Восхождение: ставит блоки под ноги или рубит дерево → крафт досок
- Авто-подбор выпавших предметов после боя
- Охрана точки: возврат в радиус после боя и лута
- Следование за игроком на заданной дистанции
- Дом: сон на кровати как точка возврата (`!sethome`, `!gohome`); если сон не удался — сохраняются текущие координаты
- Reconnect с exponential backoff 5 → 10 → 30 → 60 → 120 с
- Авто-возрождение через 1 с после смерти
- Один диспетчер команд на три источника: чат, CLI, Web GUI
- Логи в файл и дублирование в stdout, heartbeat каждые 30 с
- Smoke-тест из 12 проверок (`npm test`)

Параметры ближнего боя, константы — в `src/melee.js`:

| Параметр | Значение |
|----------|----------|
| Радиус обнаружения | 24 блока |
| Дистанция атаки | 3.0 м |
| Кулдаун удара | 600 мс |
| Потеря цели | 32 м |
| Сторожевой таймер | 30 с |

Как проходит бой:

1. Раз в 10 тиков ищется ближайший враждебный моб в радиусе
2. Цель фиксируется, в лог пишется `[⚔] Цель: <ник> @ <дистанция>м`
3. Бот догоняет моба, пока расстояние больше 3.0 м
4. В пределах дистанции — удар с кулдауном 600 мс, оружие подбирается автоматически
5. Смерть моба, отход дальше 32 м или зависшая цель — в лог `[⚔] Цель сброшена`
6. Пока цель выбрана, охрана, сбор лута и авто-лечение не мешают боту двигаться

## Требования

- Node.js ≥ 18
- Minecraft-сервер Java Edition, проверялось на 1.21.11 в offline-mode
- Windows, Linux

## Установка

```bash
git clone <url>
cd stevebot
npm install
```

После установки заполнить `config.json`: обязательны `host` и `username`.

## Быстрый запуск

| ОС | Команда | Что делает |
|----|---------|-----------|
| Windows | `start.bat` (двойной клик) | Установка при необходимости + запуск, окно держится |
| Windows | `start-debug.bat` | То же, но лог идёт в консоль |
| Windows | `start-bg.bat` | Фоновый запуск, лог в `bot_<дата>_<время>.log`, PID в `bot.pid` |
| Linux | `./start.sh` | Установка при необходимости + запуск |
| Любая | `npm start` | `node bot.js` |

Остановить бота: `Ctrl+C` в консоли или команда `quit`. Проверить работоспособность: `npm test`.

## Конфигурация

`config.json` — единственный файл настроек, в git не коммитится.

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| host | string | — | IP или домен сервера |
| port | number | 25565 | Порт Minecraft |
| username | string | — | Ник бота, не должен совпадать с ником игрока-оператора |
| version | string \| false | false | `false` — автоопределение версии сервера |
| auth | string | offline | `offline` или `microsoft` |
| reconnectDelay | number | 5000 | Запасная пауза reconnect, если расписание пустое |
| maxReconnectAttempts | number | -1 | `-1` — бесконечные попытки |
| followDistance | number | 3 | Дистанция следования за игроком |
| prefix | string | ! | Префикс чат-команд |
| guardRadius | number | 8 | Радиус охраны точки |
| combatRadius | number | 10 | Радиус поиска мобов; в коде не меньше 24 |
| autoEatStartAt | number | 14 | Порог голода для авто-еды |
| autoHealThreshold | number | 10 | HP, ниже которого бот пьёт зелье |
| autoHealCriticalThreshold | number | 6 | HP, ниже которого бот ест золотое яблоко |
| webPort | number | 3000 | Порт Web GUI |
| webToken | string | "" | Токен доступа; пусто — доступ только с localhost |
| debug | boolean | false | Диагностические логи раз в 5 с |

Пример:

```json
{
  "host": "localhost",
  "port": 25565,
  "username": "steve",
  "version": false,
  "auth": "offline",
  "reconnectDelay": 5000,
  "maxReconnectAttempts": -1,
  "followDistance": 3,
  "prefix": "!",
  "guardRadius": 8,
  "combatRadius": 10,
  "autoEatStartAt": 14,
  "autoHealThreshold": 10,
  "autoHealCriticalThreshold": 6,
  "webPort": 3000,
  "webToken": "",
  "debug": false
}
```

## Команды

Единый список для всех источников. В чате — с префиксом `!`, в CLI и Web GUI — без него.

| Команда | Аргумент | Действие |
|---------|----------|----------|
| follow | ник | Следовать за игроком (охрана снимается) |
| stop | — | Остановить следование, охрану и бой |
| guard | [радиус] | Охранять точку, радиус по умолчанию из `config.json` |
| unguard | — | Снять охрану |
| attack | — | Атаковать ближайшего враждебного моба |
| peace | — | Прекратить бой и отключить авто-атаку |
| armor | — | Надеть лучшую броню из инвентаря |
| sword | — | Взять в руку лучшее оружие |
| status | — | HP, Food, Pos, Guard, Combat, Target, Surv, Tool, Melee, Home, Loot |
| dumpitems | — | Диагностика: сколько выпавших сущностей рядом |
| sethome / setspawn | — | Установить дом (сон на кровати) |
| gohome | — | Идти к дому |
| survival | [on\|off\|toggle] | Управление выживанием, без аргумента — текущее состояние |
| clearpotions | — | Очистить чёрный список зелий |
| stats | — | Счётчики расходов: зелья, яблоки, еда |
| potions | — | Отчёт по зельям в инвентаре и реестру версии |
| help | — | Список команд |
| quit | — | Завершение работы бота |

Примеры в чате:

```text
!follow Steve     → Следую за Steve
!guard 12         → Охрана включена (радиус 12)
!status           → HP:20 Food:18 Pos:20,63,43 Guard:ON(r=8) ...
```

## Web GUI

- Адрес: `http://localhost:3000` (порт из `config.webPort`)
- 9 кнопок: `Охрана`, `Снять охрану`, `Стоп`, `Атака`, `Статус`, `Установить дом`, `Домой`, `Выживание`, `Очистить зелья`
- Плюс поле ввода для любой команды из списка и кнопка `Отправить`
- Панель статуса обновляется раз в секунду
- Две вкладки логов: игровой чат и лог бота

## CLI

- Промпт `bot> ` появляется в интерактивном терминале
- Команды вводятся без `!`
- `quit` или `Ctrl+C` — корректное завершение
